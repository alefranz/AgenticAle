# Getting started

AgenticAle runs inside a coding assistant that can invoke skills and create
independent child agents. Start by installing it for your client using the
[canonical setup guide](./setup.md).
That guide owns installation steps and routing customization.

Once installed, invoke the everyday workflow explicitly with a concrete task.
For example: `/work Fix the date filtering bug`. The session where you invoke it
coordinates the task. It does not start automatically from an ordinary coding
request.

Read the [Work skill guide](./skills/work/index.md) for its process, examples, inputs,
and outputs. For architecture and runtime support, use the canonical
[architecture](./architecture.md)
and [runtime compatibility](./runtime-compatibility.md)
references.
